# 인물 판정 Phase 1 계약

인물 시트는 SillyTavern 연결 프로필의 일반 모델이 한 번 분석한다. 출력은 `behavior`, `relationship`, `knowledge`, `speech` 종류의 영어 `rule` 최대 10개다. 목표 개수는 없고 0개도 유효하다. `src/characters/prompts.js`의 확정 문구를 그대로 사용한다. 저장 단계에서 Jev 재검증 호출을 추가하지 않는다.

시트 원문과 분석 규칙은 채팅별 전용 저장소에 보관한다. 규칙 ID는 인물 ID, 시트 해시, 분석 버전에 묶이며 시트가 바뀌면 옛 규칙을 매턴 판정에 쓰지 않는다. 시트의 빈칸은 특별한 경력·전문성·비밀 접근의 허가가 아니다. 단, 일상적인 생활 경험은 배경이 뒷받침하는 범위에서 추론할 수 있다.

매턴 Jev는 최근 RP 원문과 출처, 유효한 저장 규칙, 관련 기억·연속성 자료를 보고 활성 인물별로 필요한 규칙을 0~2개 고른다. 정보 접근·지식 범위와 반응 방향도 인물마다 따로 판단한다. RP의 주장·추측·약속·계획을 세계 사실이나 완료 행동으로 승격하지 않는다. OOC는 RP 관찰 근거가 아니다. Jev의 독립적인 답변이 서로 충돌하면 확장이 접근과 참조 관계를 확인해 유효한 선택만 남긴다.

메인 RP 모델이 원본 시트를 이미 본 인물에게는 원본을 다시 넣지 않는다. 씬판독기에만 등록한 활성 NPC에게는 최소 정체성과 이번 턴의 필요한 규칙·경계만 넣는다. Sheet Cast의 성격·관계·지식은 그 인물 시스템이 맡고, 전역 세계·갈등·사건 지시는 외부 압력과 전개를 맡는다. Generated Cast에는 별도 일반 NPC 규칙이 적용된다. 조립되는 확장 지시문은 영어이고, 길이 제한은 문장을 자르지 않고 낮은 우선순위 항목 전체를 제외해 맞춘다.

행동 방향은 계획일 뿐 사실이 아니다. 관계·사건·인물 상태는 실제 CHARACTER 출력의 이행을 확인한 뒤에만 누적한다. edit/delete/swipe/regenerate 복원과 OOC 전용 생성의 상태 변경 금지는 공통 상태 엔진을 따른다.

Phase 1 검사는 형식·시트 수정 무효화·0개/2개 선택·인물별 정보 분리·접근 거부·최종 영어 주입·모바일 화면·OOC 및 복원을 포함한다. 이후 NPC 이름 후보 읽기와 현재 RP 모델의 조용한 시트 초안 생성도 추가했다. 후보 등록과 초안 생성은 각각 사용자가 선택·저장해야 확정되며, 생성된 보완은 과거 RP 사실로 소급하지 않는다. 시트가 숨겨진 NPC에게는 영어 최소 식별 정보를 별도 보관해 활성 장면에서만 사용한다.
