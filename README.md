# 씬판독기

최근 RP 1~5턴과 채팅방별 구조화 상태를 Jev가 직접 판독하고, 지금 필요한 짧은 진행 프롬프트만 다음 응답에 주입하는 SillyTavern 확장입니다. 일반 LLM의 사전 요약 단계를 거치지 않습니다.

## 주요 기능

- 채팅 입력창 하단 돋보기 아이콘 또는 마법봉 메뉴에서 바로 여는 모바일 대응 모달
- PC와 모바일에서 버튼 문구가 세로로 쪼개지지 않는 가로형 버튼 배치
- 작게 정리한 `자동 전개`, `고급 전개`, `갈등용 진행`, `인물 판정` 네 탭과 헤더의 톱니바퀴 설정
- Jev 한 번의 요청에서 관찰·다음 진행·실행 문제·직전 출력 이행 여부를 분리 판정하고, 확장 규칙이 모순되는 진행 후보를 조정
- 판정 기준: 보수적 / 균형 / 적극적. 적극성은 사실·지식 판정을 느슨하게 만들지 않고, 현재 근거로 가능한 구체적 행동 하나를 실행하는 데만 적용
- 세계 반응 방향과 캐릭터→유저 관계 방향을 별도로 고정
- 관계 변화량과 회피·거절·고백·속마음과 행동의 불일치·취약성·질투·회복·헌신 같은 관계 비트를 분리 판정
- 과도한 망설임, 거절 반복 정체, 같은 내용 반복, 질문·선택지·허락 요구로 유저에게 진행 떠넘기기, 최근 응답의 비슷한 종결 구조, 입력 에코 흔적, 행동 실행 회피, 직전 지시 미이행을 매번 필수 판독
- 질문 떠넘기기와 입력 에코가 함께 감지되면 다음 응답에 두 교정을 함께 적용하되, 주입문이 길어지지 않도록 실행 교정은 최대 두 개만 조립
- 갈등용 진행 탭에서 부정 편향 최우선 여부와 기존 빠답의 싸움 유지, 빌런 자동, 갈등 속 NPC, 세계 적대성, NPC 특별취급 방지, 유저 불운을 관리하며 제작자 전용 원문은 잠금 해제 뒤 로컬로 추가
- RP 진행 유형: 자연, 일상, 모험·임무, 조사·미스터리, 위협·생존, 세력·암투, 전쟁·작전
- 진행 유형은 프리셋 장르가 아니라 사건 진행 방식만 제어
- 세계관에서 `프리셋 기본 세계관 사용`을 고르면 별도 세계관 전문을 주입하지 않고 현재 프리셋·로어북의 설정을 그대로 사용하며 진행 방향만 적용
- 고급 전개는 일상·교류 / 탐험·발견 / 사건·목표 / 추리·수사 / 위협·전투 / 공포·초자연 / 암투·공작 / 관계·치정 중 켜 둔 요소 하나만 맥락에 맞을 때 사용. 개방도는 18% / 35% / 58% / 75% 네 단계
- Jev는 진입 가능성·원인 경로·즉시 실행 단계만 짧게 판정하고, 실제 사건·인물·크리처·집단은 확장의 준비된 표에서 추첨해 토큰 사용을 제한
- 고급 전개가 켜진 동안 기본 RP 진행의 사건 생성은 잠시 비활성화되며, 관계·호흡·NPC 지식·사건 해결 속도·갈등용 진행은 계속 함께 작동
- 고급 사건은 하나만 유지하고 자동으로 새 사건으로 교체하지 않음. 상시 현황판의 **사건 끝내기**를 누르면 다음 적합한 기회부터 새 사건을 판정
- 세계관은 고급 전개와 독립적으로 하나만 선택. 기본 세계관 11종과 사용자가 준 일반세계·해리포터·메이저장르·웨어울프·오메가버스 전문을 제공하고, 접힌 목록형 관리자에서 커스텀 추가·수정·삭제·JSON 복사/가져오기를 지원
- 커스텀 세계관은 이름과 전문만 저장하면 Jev 라우팅용 짧은 힌트를 로컬에서 자동 생성하므로 별도 모델 호출이나 추가 API 키가 필요 없음
- `현대 대학·캠퍼스` 세계관은 배경 국가와 학교에 맞춰 미국·영국의 학기, 기숙사, 동아리, 시험, 홈커밍·미식축구 시즌 등을 섞지 않고 적용하며 자체로 큰 사건을 강제하지 않음
- 관계 진전 속도와 사건 해결 속도를 각각 느리게 / 중간 / 빠르게 설정
- 전체 RP 호흡을 별도로 설정하고, Jev가 사소한 반응의 압축·자연 호흡·중요한 순간 확대를 판독
- 적극 판정도 한 응답의 주요 비트 하나만 움직이며 전체 RP 호흡·관계 속도·사건 해결 속도를 건너뛰지 않음
- 유저 입력을 문장별로 되받지 않고 주요 실행 하나와 직접 연결된 보조 비트만 조립
- 새 빌런·일반 NPC의 공통 등장 확률과 별도의 새 사건 발생 확률
- 장르별 완성 사건표, 일반 NPC표, 빌런표에서 추첨하고 채팅별 프로필 유지
- NPC가 필요할 때만 역할·장면 비중·지식 범위·정보 사용 태도를 판정하고, 미리 작성된 짧은 실행문을 조합
- NPC의 눈치·직감·의심은 직접 관찰한 단서에서 넓은 표면 상태를 추측하는 데만 사용하며, 접근할 수 없는 비밀의 정체·원인·관계·계획을 맞히는 우회로로 사용하지 않음
- 생성 NPC의 목적·이해관계·제약·입장 변화 조건을 고정해 장면마다 성격이 바뀌는 현상을 방지
- 같은 입력의 재생성에는 기존 판정과 추첨을 재사용하고, 같은 장면의 실패 추첨은 반복하지 않음
- 관계·사건·NPC 계획은 `pending`으로 보관하고, 다음 Jev 판독에서 실제 캐릭터 출력의 이행을 확인한 뒤 수행된 부분만 확정
- 이번 턴의 `none`·`unclear`는 이전에 확정된 로맨스·신뢰·친밀감·사건 상태를 자동으로 삭제하지 않으며, 같은 캐릭터 출력의 관계 원인은 중복 카운트하지 않음
- 캐릭터 출력을 리롤·수정·삭제하면 그 출력으로 확정된 관계·사건·NPC·추첨 상태를 직전 상태로 자동 복원하고 토스트로 알림
- 관계·사건 복원 기록, 설정, 커스텀 세계관, 인물 시트와 판독값, Jev 키는 SillyTavern 사용자 데이터의 `scene-reader` 전용 폴더에 분리 저장
- 날짜·시간 백업 생성, 목록 복원, JSON 다운로드·가져오기·삭제를 지원하며 복원 직전 상태도 자동 백업
- OOC-only 입력은 Jev와 주입을 건너뛰고 기존 주입을 비우며 토스트로 알림. 대소문자를 구분하지 않는 `(OOC: ...)`·`[OOC: ...]`와 OOC_CHAT의 `extra.ooc_chat=true`를 인식
- RP+OOC 혼합 입력은 같은 최근 턴 범위에서 역할을 분리해 RP만 관찰 근거로 사용하고 OOC는 다음 진행의 방향·제약으로만 참고. OOC 원문을 씬판독기 주입문에 복사하지 않음
- 과거 OOC는 현재 명령 큐로 재실행하지 않고, 아직 유효한 세계 사실·지식 제한·관계 상태·지속 제약만 연속성 참고로 사용
- 전송 시 토스트에서 입력 확인, Jev 판독, 주입문 조립, 적용 완료 상태를 확인
- 최종 적용 요약과 장면·관계 / 사건·NPC / 갈등·실행 / 저장·주입문 접이식에서 Jev 원선택, 확신도, policy 결과, coordinator 최종값, 변경 이유, 추첨, pending과 실제 이행·저장 결과를 확인
- 최종 적용 바로 아래의 상시 현황판에서 사건·일반 NPC·빌런의 실행 상태와 긍정·부정·양쪽 방향 확인
- 기본 판정·전개와 세계관 전문의 주입 위치를 각각 선택. `{{scene-reader}}`와 `{{scene-reader-world}}` 매크로를 프리셋의 서로 다른 위치에 둘 수 있음
- 전체 사용 스위치를 끄면 Jev 호출과 모든 주입을 즉시 중단
- 비밀번호로 한 번 여는 제작자 모드에서만 로컬 전용 원문을 등록하고 채팅별로 활성화
- 인물 판정 탭에서 캐릭터·페르소나·NPC 시트를 한 명씩 저장하고, Jev가 명시 근거·역할 추론 범위·지식/접근 상한·성향 적용 범위·짧은 시트 여부를 구조화
- 짧거나 구버전인 시트의 누락 정보는 무능·평범한 성격으로 고정하지 않고 `미지정`으로 보존하며, 직업·형용사 하나를 전문성·전지적 지식·획일적 캐해로 확대하지 않음
- 매턴 현재 장면과 관련된 인물 최대 3명을 최근 언급과 주 캐릭터 우선으로 골라 각자의 지식 출처·주제 능력·접근·확신·반응을 따로 판정
- 메인 모델이 이미 보는 원본 시트는 중복 주입하지 않고 이번 턴 경계만 넣으며, 씬판독기에만 저장한 활성 NPC는 짧은 핵심 정보와 경계를 함께 주입

제공된 빠답은 원래의 바깥쪽 `Meta:` 외피만 공통 지시문으로 옮겼습니다. 나머지 태그, 문장, 순서, 매크로는 원문 그대로 보존하며 정적 검사에서 각 블록의 해시를 확인합니다.

## 설치

두 부분을 모두 설치해야 합니다. 자세한 순서는 [INSTALL.md](INSTALL.md)에 있습니다.

1. SillyTavern의 확장 설치 화면에 `https://github.com/bongbong11/-_-.git`을 입력합니다.
2. [서버 플러그인 전용 ZIP](downloads/scene-reader-jev-plugin-v0.4.0.zip)을 받아 압축을 푼 `scene-reader-jev` 폴더를 SillyTavern의 `plugins` 안에 넣습니다.
3. `config.yaml`의 `enableServerPlugins`를 `true`로 바꾸고 SillyTavern을 다시 시작합니다.

내장 CORS 프록시는 사용하지 않으므로 `enableCorsProxy` 설정은 필요 없습니다.

## 사용

1. 마법봉 메뉴에서 **씬판독기**를 엽니다.
2. 오른쪽 위 **톱니바퀴**에서 Jev API 키를 저장하고 **연결 확인**을 누릅니다.
3. **자동 전개**에서 세계관, 세계 반응, 캐릭터→유저 관계 방향, 판정 기준, RP 진행 유형과 속도를 선택합니다.
4. 필요하면 **고급 전개**에서 전개 개방도와 사용할 요소를 켜고, 저장한 세계관을 관리합니다.
5. **갈등용 진행**에서 부정 편향 최우선 여부와 사용할 빠답 항목을 켭니다.
6. 필요하면 **설정 → 주입 위치**에서 매크로 방식을 선택하고 `{{scene-reader}}`, `{{scene-reader-world}}`를 활성 프리셋의 원하는 위치에 한 번씩 넣습니다.
7. 자동 판독을 켜면 다음 생성 직전에 최근 채팅을 읽고 필요한 블록만 주입합니다. **지금 판독**으로 수동 확인도 할 수 있습니다.

Jev 주소는 `https://api.typesafe.ai/v1/systemone`, 모델은 `jev-latest`로 서버 플러그인에 고정되어 있습니다. 키는 SillyTavern 사용자별 `scene-reader/secrets.json`에 저장되며 브라우저에 남기지 않습니다.

제작자 전용 원문은 배포 파일에 포함되지 않습니다. 잠금 해제 후 직접 붙여 넣은 내용만 사용자별 씬판독기 전용 저장소에 보관됩니다.

`인물 판정 사용`을 켜고 필요한 캐릭터/NPC 시트를 저장했다면 프리셋의 `CHARACTER_KNOWLEDGE_AND_CONTEXT`, `ACTIVE_HISTORY`, `CANON_NPC_POLICY`는 중복을 피하기 위해 끌 수 있습니다. 인물 판정을 끄거나 필요한 시트를 저장하지 않은 채팅에서는 기존 프롬프트를 유지하세요. 세계관·문체·장면 연속성 프롬프트는 인물 판정의 대체 대상이 아닙니다.

## 판독 범위

씬판독기는 최근 화면상 채팅 1~5턴과 확장이 이 채팅에 저장한 관계·사건·생성 NPC 상태만 읽습니다. 한 턴은 유저 입력에서 시작해 뒤따르는 캐릭터 출력까지이며, 생성 직전에는 현재 유저 입력이 최신 미완성 턴으로 포함됩니다. 매우 긴 기록은 최신 내용을 우선해 제한합니다. 숨김 처리된 기억, 로어북, 프리셋 전체를 해석하지 않습니다. NSFW 장면도 읽을 수 있지만 성적 장면의 진행·완화·중단·종료 여부는 판정하지 않습니다.

OOC_CHAT과 함께 사용할 때는 송신 확장이 USER 메시지에 `extra.ooc_chat=true`를 유지하면 텍스트 정규식보다 이 표식을 우선합니다. 실제 OOC 본문은 메시지의 `mes`에서 읽으며 `extra.ooc_instruction`은 본문으로 사용하지 않습니다.
