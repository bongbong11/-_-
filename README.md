# 씬판독기

최근 롤플레잉 대화를 읽고, 다음 답변에 필요한 진행과 인물의 반응 기준을 골라주는 SillyTavern 확장입니다. 이야기를 대신 완성하거나 모든 문제를 해결시키는 기능은 아닙니다. 현재 대화가 자연스럽게 움직이도록 돕습니다.

**화면 확장 0.19.2 · Jev 서버 플러그인 0.6.0**

Character Reasoner의 인물 분석 기능이 씬판독기 안에 포함되어 있습니다. **Character Reasoner 확장을 따로 설치할 필요는 없습니다.** 다만 Jev 연결과 저장을 담당하는 아래 서버 플러그인은 필요합니다.

## 처음 사용하는 분께

1. 아래 순서로 확장과 서버 플러그인을 설치합니다.
2. 씬판독기의 톱니바퀴를 열어 **Jev API 키 → 키 저장 → 연결 확인**을 누릅니다.
3. **자동 전개**에서 기본 전개 성향을 **균형**으로 두고 먼저 사용해 봅니다.
4. 인물 판정 탭에서 **분석 명령문 복사**로 외부 AI에 판독시트를 만들게 한 뒤, 받은 JSON을 **검증 후 저장·적용**합니다. 이미 만든 JSON이 있다면 바로 가져오면 됩니다.
5. 고급 전개와 갈등용 진행은 원하는 기능만 켭니다. 처음부터 모두 켤 필요는 없습니다.

설정은 처음에는 기본값으로 두세요. 진행이 답답하거나 과할 때만 톱니바퀴 안의 **진행 적극성**을 조금씩 조절하면 됩니다.

## 설치

### 1. 화면 확장

SillyTavern의 **확장 → 확장 설치**에 다음 주소를 입력합니다.

```text
https://github.com/bongbong11/-_-.git
```

설치 후 화면을 새로고침합니다. **실리태번 확장 탭 → 씬판독기**를 펼치면 **씬판독기 사용**, **채팅창 아이콘 표시**, **씬판독기 열기**가 있습니다. 이 항목은 처음에는 접혀 있습니다.

채팅 입력창 옆 아이콘이나 마법봉 메뉴에서도 열 수 있습니다. 아이콘 표시를 꺼도 판독 기능은 계속 사용할 수 있고, 실리태번 확장 탭의 **씬판독기 열기**로 화면을 열면 됩니다.

수동 설치는 [화면 확장 ZIP](downloads/scene-reader-sillytavern-v0.19.2.zip)을 사용하세요. 압축 안의 `scene-reader` 폴더를 화면 확장 폴더에 넣습니다. 이미 설치했다면 기존 폴더의 내용을 업데이트하고, 같은 확장을 두 개 설치하지 마세요.

### 2. Jev 서버 플러그인

[서버 플러그인 ZIP](downloads/scene-reader-jev-plugin-v0.6.0.zip)을 풉니다. 안에 있는 **scene-reader-jev 폴더 전체**를 SillyTavern의 **plugins** 폴더에 넣습니다.

최종 위치는 다음과 같습니다.

```text
SillyTavern/plugins/scene-reader-jev/package.json
SillyTavern/plugins/scene-reader-jev/index.cjs
SillyTavern/plugins/scene-reader-jev/storage.cjs
```

SillyTavern의 `config.yaml`을 메모장으로 열고 다음 설정을 켭니다.

```yaml
enableServerPlugins: true
```

저장한 뒤 **SillyTavern을 완전히 종료하고 다시 시작**하세요. 브라우저 새로고침만으로는 서버 플러그인이 켜지지 않습니다. `enableCorsProxy`는 켤 필요가 없습니다.

이미 서버 플러그인 **0.6.0**을 사용한다면 다시 설치할 필요가 없습니다. 이전 버전은 해당 플러그인 폴더만 교체하세요. 사용자 데이터 폴더나 다른 플러그인은 삭제하지 마세요.

휴대전화에서도 서버가 실행되는 SillyTavern 폴더의 `plugins`에 넣어야 합니다. 브라우저의 다운로드 폴더에 파일을 받기만 해서는 설치되지 않습니다. 다른 사람이 운영하는 서버라면 서버 관리자에게 설치를 요청하세요.

### 3. 연결하기

씬판독기 오른쪽 위 **톱니바퀴 → 모델 연결 → Jev 판독**에서 TypeSafe Jev API 키를 입력합니다. **키 저장**, **연결 확인**을 차례로 누르세요. 주소와 모델은 정해져 있으므로 입력하지 않습니다.

외부 AI에서 만든 판독 JSON을 가져오는 데에는 별도의 연결 프로필이 필요하지 않습니다. 씬판독기 안에서 **연결 모델로 추출**하거나 **연속성 추론**을 사용할 때만 모델 연결을 설정하세요. SillyTavern의 **API 연결 메뉴에 연결 프로필을 저장**한 뒤, 씬판독기 설정의 **SillyTavern 연결 프로필**에서 선택하세요. **프로필 새로고침**을 누르면 새로 저장한 연결이 목록에 나타납니다. 이 연결은 인물 기록 추출과 선택 기능인 연속성 추론에 사용합니다.

## 업데이트할 때

먼저 설정의 **데이터 백업 → 지금 백업**으로 저장본을 남겨두는 것을 권합니다. 확장 관리 화면에서 업데이트한 뒤 새로고침하세요. ZIP으로 업데이트할 때는 `src` 폴더를 포함해 압축 내용 전체를 기존 확장 폴더에 덮어씁니다.

**0.16.3 이하의 인물 규칙은 새 방식으로 다시 추출해야 합니다.** 인물 판정 탭에서 새 판독 JSON을 가져오거나, 저장한 시트를 열고 **연결 모델로 추출**을 누르세요. 기존 자료는 보관되지만, 재추출 전에는 새 인물 기록으로 적용되지 않습니다.

나중에 인물 분석 기준이 업데이트되면 일부 시트에 **재판독 필요**가 표시될 수 있습니다. 그때도 원문을 확인하고 다시 추출하면 됩니다. 원문을 매번 새로 입력할 필요는 없습니다.

## 자동 전개

평소 대화·감정·행동의 흐름을 정하는 탭입니다. 작은 행동이나 대화의 변화도 진행으로 봅니다. 고급 전개를 끈 상태에서도 작동합니다.

### 세계 반응과 관계 방향

**세계 반응**은 주변 상황이 어떻게 반응할지, **관계 방향**은 인물이 사용자에게 보이는 기본적인 태도를 정합니다. 호의적이라고 바로 사랑에 빠지거나, 적대적이라고 모든 사건이 적대적으로 바뀌는 것은 아닙니다. 인물의 실제 시트와 대화 근거를 함께 따릅니다.

### 기본 전개 성향

| 선택 | 중심이 되는 진행 |
|---|---|
| 정적 | 두 사람의 관계·감정·생각, 의미 있는 대화의 변화 |
| 균형 | 감정·대화와 행동·주변 반응을 상황에 맞게 섞음 |
| 동적 | 활발한 행동·상호작용·주변 반응, 상황을 움직이는 시도 |

정적은 아무것도 하지 않는다는 뜻이 아닙니다. 조용한 대화에서 새로운 속내가 드러나도 진행입니다. 동적이라고 무조건 큰 사건을 만들거나 관계를 빨리 바꾸지는 않습니다.

말과 분위기만 바뀌고 같은 내용을 반복하면, 대화의 접근을 바꾸거나 작은 행동을 시도하도록 돕습니다. 모든 문제를 한 번에 해결하거나 상대의 선택까지 대신 결정하지는 않습니다.

**글의 길이·서술 속도·장르·문체는 메인 프롬프트와 프리셋을 따릅니다.** 별도의 RP 호흡 설정은 없습니다.

### 관계 진전 속도

가까워지거나 멀어지는 변화의 폭입니다. 느리게는 작은 변화와 쌓인 계기를, 빠르게는 충분한 계기가 있을 때 더 큰 변화를 허용합니다. 호감뿐 아니라 거리 두기·거절·갈등에도 적용됩니다.

느리게 해도 같은 말을 반복해야 하는 것은 아닙니다. 동적으로 설정해도 관계만 천천히 변하게 할 수 있습니다.

### 사건 해결 속도

진행 중인 문제를 이번 답변에서 얼마나 해결에 접근시킬지 정합니다. 느리게는 단계별 진전을, 빠르게는 조건이 갖춰졌을 때의 해결을 우선합니다. 이미 해결된 일을 일부러 되돌리거나, 해결 근거가 없는데 끝내지는 않습니다.

### 공통 인물 등장 확률

새 일반 NPC와 새 빌런의 등장 추첨에 사용합니다. **5·10·20·35·50·100%** 중 선택합니다.

추첨에 당첨되면 장면에 자연스럽게 등장할 방법이 있는지 판정합니다. 방문·마주침·현재 활동 참여·주변 인물의 개입·연락 등 상황에 맞는 방법을 고릅니다. 정적인 장면에도 사람이 등장할 수 있습니다.

100%는 등장 추첨을 통과한다는 뜻입니다. 장소나 설정상 불가능한 등장까지 강제하지는 않습니다. 같은 입력을 다시 판독할 때 계속 재추첨하지 않으며, 기존 인물이 행동하는 데에는 등장 추첨이 필요하지 않습니다.

### 지금 판독과 결과

**지금 판독**을 누르면 현재 입력과 최근 대화를 확인합니다. **이번 턴 최종 적용**에서 실제로 선택된 진행을 먼저 확인하세요. 그 아래에서 현재 사건·인물과 자세한 판정 내용을 볼 수 있습니다.

여러 기능을 켜도 전부를 별도 사건으로 넣지는 않습니다. 중심 진행 하나와 함께 가능한 보조 진행을 고릅니다. 인물 기록은 그 안에서 인물의 반응을 맞추는 기준으로 쓰입니다.

**검증 대기**는 계획을 골랐지만 실제 답변에서 실행됐는지 아직 확인하지 않았다는 뜻입니다. 선택했다고 바로 발생한 일로 저장하지 않습니다. **사건 끝내기**는 확장이 추적하는 사건을 정리하는 버튼이며, 실제 채팅을 수정하지 않습니다.

## 고급 전개

기본 흐름 위에 별도의 이벤트를 더하는 기능입니다. **고급 전개 사용**을 켜고 원하는 요소를 선택하세요. 탐험·위협·세력·비밀 등 화면에 있는 요소 중 필요한 것만 켜면 됩니다.

고급 전개를 켜도 기본 전개 성향과 관계·해결 속도는 계속 적용됩니다. 이벤트가 불발돼도 현재 대화와 행동은 이어갑니다.

**고급 이벤트 발생 확률**은 18·35·58·75% 중 선택합니다. 새로운 이벤트에만 적용하며 이미 진행 중인 이벤트는 다시 추첨하지 않습니다. 사건의 크기나 글의 속도를 정하는 설정은 아닙니다.

### 세계관 선택과 관리

세계관은 가능한 상황의 큰 틀을 제공합니다. 실제 장르와 문체는 프리셋을 따릅니다. 특정 요소를 켰다고 세계 설정에 없는 능력이나 존재를 자동으로 추가하지 않습니다.

**세계관 관리**를 펼치고 **+**를 눌러 이름과 세계관 원문을 저장하세요. **짧은 세계관 설명**에는 판독에 필요한 큰 규칙만 적습니다. 비우면 원문에서 짧은 참고문을 만듭니다. 저장한 세계관은 목록에서 다시 열어 수정하거나 삭제할 수 있습니다.

**원작·프랜차이즈 세계**를 켜면 장소·시대·역할에 맞는 원작 인물도 등장 후보로 고려합니다. 무조건 유명 인물을 등장시키는 옵션은 아닙니다.

세계관 원문은 본문 모델에 전달하고, Jev에는 짧은 설명을 참고시킵니다. 원문 전체를 Jev가 읽는 것은 아닙니다. 세계관 원문을 어디에 넣을지는 아래 **주입 위치**에서 선택합니다.

일반 주입문에도 현재 선택한 세계관 이름을 한 줄로 표시합니다. 세계관 원문은 지정한 위치로 전달됩니다.

## 갈등용 진행

싸움 유지·빌런·NPC의 자율적인 반응·세계 적대성 등 원하는 항목만 사용하세요. 실제 갈등이 없는 장면을 무조건 싸움으로 바꾸는 설정은 아닙니다.

**부정 편향을 최우선으로 사용**은 이 탭에서 켠 부정적 방향을 주변 상황과 사건 진행에서 우선하도록 합니다. 등록한 인물의 성격·관계·지식을 지우는 기능은 아닙니다. 부정적 항목을 많이 켜면 진행 적극성과 무관하게 이야기 분위기가 거칠어질 수 있으니 목적에 맞게 선택하세요.

## 인물 판정

시트에서 필요한 정보를 정리해 두고, 이번 장면에서 그 인물이 어떻게 말하고 행동하고 생각할지에 필요한 기준만 골라 씁니다. 매턴 시트 전체를 다시 분석하지 않습니다.

### 판독시트 만들고 가져오기

이미 캐릭터 리즈너나 외부 AI에서 만든 JSON이 있다면 **판독시트 가져오기**에 바로 붙여 넣으세요. **JSON 파일 불러오기**를 누르거나 입력칸에 파일을 끌어놓아도 됩니다. 저장 이름을 비우면 JSON의 인물 이름을 사용합니다. **검증 후 저장·적용**을 누르세요.

새로 만들 때는 다음 순서로 진행합니다.

1. 캐릭터·페르소나·NPC에서 **+**를 눌러 원문 입력칸을 엽니다.
2. 캐릭터와 페르소나는 **현재 시트 가져오기**를 누르거나 직접 붙여 넣습니다. NPC는 한 명의 시트를 입력합니다.
3. 캐릭터와 페르소나에 연결된 로어북은 자동으로 읽습니다. 화면에서 읽힌 내용을 확인하세요. NPC는 직접 입력한 한 명의 시트를 사용합니다.
4. **분석 명령문 복사**를 눌러 사용하는 외부 AI에 붙여 넣습니다. 시트를 저장하지 않고도 복사할 수 있습니다.
5. AI가 돌려준 JSON을 **판독시트 가져오기**에 넣습니다. 필요한 경우 저장 이름을 적습니다.
6. **검증 후 저장·적용**을 누릅니다. 인물 종류와 이름은 결과 JSON을 따라 등록됩니다.

가져오기는 JSON의 형식과 기록 규칙을 검사합니다. 원문 내용과 일치하는지까지 다시 판독하지는 않으므로, 처음 저장할 때 기록을 읽어 보세요. 잘못된 JSON은 저장하지 않으며 기존 정상 기록을 유지합니다.

### 날짜별 버전 관리

같은 인물 종류와 저장 이름으로 가져오면 **날짜별 판독시트**에 버전이 쌓입니다. 최신으로 가져온 결과가 적용되며, **이 버전 적용**으로 과거 버전을 다시 선택할 수 있습니다. 같은 인물을 중복 생성하지 않습니다.

**보기·복사·다운로드·삭제**로 각 버전을 관리합니다. 적용 중인 버전을 삭제하면 그 인물의 기록 적용도 해제됩니다. 인물 등록 자체는 남습니다. 삭제 후 다른 버전을 적용하거나 새 결과를 가져오세요.

### 연결 모델로 바로 추출하기

외부 AI에 복사하는 대신, SillyTavern에 저장한 연결 프로필로도 만들 수 있습니다. 설정에서 프로필을 선택하고 인물 원문과 로어북을 **시트 저장**한 다음 **연결 모델로 추출**을 누르세요. 결과는 날짜별 버전으로 저장하고 적용합니다.

원문·이름·연결된 로어북을 수정하면 기존 적용 기록은 다시 판독해야 합니다. **연결 로어북 새로고침**으로 바뀐 내용을 다시 읽을 수 있습니다.

### 이번 장면에 반영되는 방식

기록은 성향·가치관·관계·지식·반응·표현·경계·능력 등으로 나뉩니다. 문장은 영어로 표시될 수 있습니다. 펼치면 대상·조건·출처를 확인할 수 있으며, 외부 JSON만 가져온 경우에는 출처 번호만 있고 원문은 없을 수 있습니다. **알고 있음·믿음·의심·오해·모름**은 서로 다르게 유지됩니다.

매턴 관련 후보를 추린 뒤 Jev가 인물당 필요한 기록을 최대 네 개 선택합니다. **이번 턴 인물 판정**에서 새 기록의 사용 여부, 전달한 후보 수와 실제 선택·주입 내용을 확인할 수 있습니다. 선택이 0개라고 인물이 사라지거나 새 NPC로 취급되지는 않습니다.

### 원본을 본문 모델도 읽는 경우

**메인 RP 모델도 이 원본 시트를 이미 읽음**은 캐릭터 카드·페르소나·활성 로어북으로 같은 내용이 본문 모델에 전달될 때 켭니다. 원문을 다시 길게 넣지 않기 위한 설정입니다.

씬판독기에만 저장한 NPC라면 끄세요. 등장할 때 필요한 최소 정체성과 선택한 기록을 짧게 함께 전달합니다.

### 페르소나와 사칭 허용

페르소나는 기본적으로 사용자의 인물입니다. **유저 사칭 허용**을 켰을 때만 이 인물을 행동·대사 후보로 함께 판정합니다. 페르소나에 적힌 비밀이나 속마음이 다른 인물의 지식으로 자동 전달되지는 않습니다.

### 인물 삭제와 오류 로그

등록한 인물은 목록이나 기록 보기에서 **삭제**를 바로 누를 수 있습니다. 날짜별 판독시트는 별도로 남으므로, 그 결과를 다시 적용하면 인물 등록이 복원될 수 있습니다.

판독시트 가져오기·추출·저장에서 오류가 나면 **오류 로그 복사**를 눌러 문의할 때 보내 주세요. 로그에는 오류 단계와 형식 정보만 담고 시트 원문·대화·JSON 내용은 담지 않습니다.

### 친밀한 장면

스킨십이나 성적 긴장은 대화·행동·사건과 함께 나타날 수 있습니다. 별도 사건 칸을 차지하거나 키스만으로 장면 모드가 바뀌지 않습니다. 실제 성적 활동이 시작되었다고 확인되면 씬판독기의 동적 진행 주입을 잠시 쉬고, 고정 설정과 참여 인물의 저장된 참고 정보만 남깁니다. 장면이 끝났다고 확인되면 일반 판독을 재개합니다. 수위와 구체적인 묘사는 사용하는 프리셋과 인물 시트를 따릅니다.

같은 상호작용 안에서 잠시 대화하거나 쉬는 것만으로는 종료로 처리하지 않습니다. 참여에서 빠진 인물의 참고문은 제외합니다. 판정에 사용한 메시지를 수정·삭제하거나 다른 답변으로 바꾸면 이전 판정을 비우고 다음 판독에서 다시 확인합니다.

## 톱니바퀴 설정

### 전체 사용과 자동 판독

**씬판독기 전체 사용**을 끄면 판독과 주입을 중단합니다. 저장된 시트나 채팅 내용은 삭제하지 않습니다.

**생성 직전에 자동 판독**을 끄면 필요할 때 **지금 판독**을 눌러야 합니다. 입력이나 설정이 바뀌었다면 새 판독이 필요합니다.

### 진행 적극성

기본값은 **1.0**입니다. 숫자칸의 위아래 화살표로 **0.1씩**, **0.5~1.5** 범위에서 바꿉니다.

- 진행이 너무 답답하면 1.1부터 조금씩 올립니다.
- 너무 많은 진행을 시도하면 0.9부터 조금씩 내립니다.
- **1.0으로 복원**을 누르면 기본값으로 돌아갑니다.

현재 채팅의 대화·행동·기존 상황 진행을 얼마나 쉽게 채택할지 조절합니다. 가장 신중하게 해도 기본 반응과 작은 시도는 남습니다. 정적·동적 성향, 관계·해결 속도, 등장 확률, 인물의 지식, 실제 실행 여부를 확인하는 기준은 바꾸지 않습니다. 변경 후 새 판독부터 적용됩니다.

### 최근 채팅 범위와 확신도

**최근 채팅 범위**는 1~5턴이며 기본은 3턴입니다. 한 턴은 유저 입력과 그 뒤의 캐릭터 답변입니다. 답변 생성 직전의 현재 입력도 한 턴으로 세므로, 1턴은 직전 캐릭터 답변이 빠질 수 있습니다. 앞뒤 흐름을 보려면 2턴 이상을 사용하세요.

**화면에 확신도 표시**는 결과의 자세한 수치를 보여주는 설정입니다. 끈다고 실제 판정이 달라지지는 않습니다. 확신도는 실제 정답률이나 등장 확률을 뜻하지 않습니다.

### 연속성 추론

앞서 나온 약속·일정·책임·중요한 정보 전달을 이후 장면에 연결하도록 돕습니다. 보조 모델이 찾은 후보를 확인한 뒤 사용합니다. 에코나 반복을 잡는 기능과는 별개입니다.

**연속성 추론 사용**과 **연결 프로필 선택**은 별개입니다. JSON만 가져온다면 연결 프로필이 없어도 됩니다. 연결 모델로 인물 기록을 추출하더라도 연속성 추론을 켤 필요는 없습니다.

### 주입 위치

주입은 본문 모델이 답변을 만들 때 참고할 지시문을 함께 보내는 것입니다. 별도 채팅 메시지를 추가하는 것은 아닙니다.

처음에는 **기본 · 깊이 0 · system**을 사용하면 됩니다. 프리셋 안의 특정 위치에 넣고 싶다면 항목별로 **프리셋 · 매크로 위치**를 선택하고, 프리셋의 원하는 칸에 아래 문구를 한 번만 넣으세요.

| 넣을 내용 | 프리셋에 넣는 문구 |
|---|---|
| 기본 판정·진행·인물 기준 | `{{scene-reader}}` |
| 선택한 세계관 원문 | `{{scene-reader-world}}` |

각각 독립적으로 선택할 수 있습니다. 매크로 방식으로 정한 항목은 기본 위치에 중복해서 넣지 않습니다.

### 백업과 초기화

**지금 백업**은 현재 설정·세계관·인물 자료·저장 상태를 보관합니다. **다운로드**로 다른 곳에 보관하고, **백업 가져오기**로 복원할 수 있습니다. 다운로드 백업에는 API 키가 포함되지 않습니다.

초기화 버튼은 이름에 표시된 확장 상태만 지웁니다. 실제 채팅을 지우는 버튼은 아닙니다. 필요하면 먼저 백업하세요.

## 자주 묻는 문제

**버튼이 보이지 않아요.** 확장을 설치한 뒤 새로고침하고, 확장 관리에서 씬판독기가 켜져 있는지 확인하세요.

**404가 나와요.** Jev 서버 플러그인의 폴더 위치와 `enableServerPlugins`를 확인한 뒤 SillyTavern을 완전히 재시작하세요.

**401·403이 나와요.** Jev 키를 다시 확인하고 저장하세요. 키 전체를 공개 채팅이나 문의 글에 올리지 마세요.

**시간 초과·502가 나와요.** SillyTavern 서버가 Jev에 연결하지 못했을 수 있습니다. 잠시 뒤 연결 확인을 다시 해보세요.

**인물 기록이 저장되지 않아요.** 오류 안내와 **오류 로그 복사**를 확인하세요. 연결 모델로 추출한다면 연결 프로필과 시트 저장 상태도 확인하세요. 잘린 응답이나 잘못된 기록은 저장하지 않으며, 기존 정상 기록은 유지합니다.

**판정했는데 인물이 안 나와요.** 등장 확률은 추첨 확률입니다. 당첨 후에도 장면에 맞지 않으면 등장하지 않을 수 있습니다. 결과의 선택·제외 이유를 확인하세요.

**진행이 답답해요.** 관계 속도를 빠르게 바꾸기 전에 반복이 실제로 있었는지 결과를 확인하고, 진행 적극성을 조금 올려보세요. 인물의 정보 부족이나 사용자의 결정을 기다려야 하는 상황은 적극성으로 없애지 않습니다.

**OOC에서는 어떻게 되나요?** OOC만 있는 입력은 판독·주입을 건너뜁니다. RP와 OOC가 섞이면 실제 RP와 지시를 구분합니다. 에코·반복 점검은 연속성 추론을 꺼도 작동합니다.

**문의할 때 무엇을 보내나요?** 문제가 생긴 상황과 인물 판정의 **오류 로그 복사** 결과를 알려주세요. 다른 화면의 판정 결과를 복사했다면 공유하기 전에 개인정보를 확인하세요.

실제 답변은 본문 모델이 작성합니다. 같은 설정이라도 모델·프리셋·장면에 따라 결과가 달라질 수 있습니다.
