## 설치와 업데이트

**화면 확장과 서버 플러그인을 모두 설치해야 합니다.** 화면 확장만 설치하면 키 저장·판독·서버 저장 기능을 사용할 수 없습니다.

### 1. 화면 확장 설치

SillyTavern의 **확장 → 확장 설치(Install Extension)** 에 아래 주소를 입력합니다.

~~~text
https://github.com/bongbong11/-_-.git
~~~

설치 후 페이지를 새로고침합니다. 마법봉 메뉴의 **씬판독기** 또는 채팅 입력창 주변의 **돋보기 아이콘**으로 열 수 있습니다.

수동 설치용 파일은 [화면 확장 ZIP](downloads/scene-reader-sillytavern-v0.16.1.zip)입니다. 기존 확장을 업데이트한다면 현재 확장 폴더에 내용 전체를 덮어쓰세요. 새로 나뉜 파일과 src 폴더도 모두 필요합니다. 같은 확장을 다른 이름으로 한 번 더 설치하지 마세요.

### 2. 서버 플러그인 설치

[서버 플러그인 ZIP](downloads/scene-reader-jev-plugin-v0.6.0.zip)을 풀고, 안의 **scene-reader-jev 폴더 전체**를 SillyTavern의 plugins 폴더에 넣습니다.

최종 위치는 다음과 같습니다.

~~~text
SillyTavern/
  plugins/
    scene-reader-jev/
      index.cjs
      storage.cjs
      package.json
~~~

이미 package.json이 있어도 **이 플러그인 폴더 안의 파일 세 개를 함께 교체**하면 됩니다. SillyTavern 본체나 다른 플러그인의 package.json을 바꾸는 것이 아닙니다. 별도 패키지 설치는 필요 없습니다.

SillyTavern의 config.yaml에서 다음 항목을 확인합니다.

~~~yaml
enableServerPlugins: true
~~~

플러그인을 새로 설치하거나 교체했다면 **SillyTavern을 완전히 종료하고 다시 실행**하세요. 이미 true여도 파일을 교체했다면 재시작이 필요합니다. enableCorsProxy는 켤 필요가 없습니다.

### 업데이트할 때

- 화면 확장은 SillyTavern의 확장 업데이트 기능을 사용한 뒤 페이지를 새로고침합니다.
- **플러그인 v0.6.0을 이미 설치했다면 이번 화면 업데이트 때문에 다시 교체할 필요는 없습니다.**
- 더 오래된 플러그인은 위 ZIP의 폴더 전체로 교체하고 서버를 재시작합니다.
- 사용자 데이터의 scene-reader 폴더는 지우지 마세요. 확장 소스와 실제 저장 데이터는 다른 위치에 있습니다.
- 업데이트 전 설정의 **지금 백업**으로 보관해 두면 이전 상태를 복원할 수 있습니다.

설치만 빠르게 보려면 [별도 설치 안내](INSTALL.md)를 참고하세요.

## 처음 사용하기

1. 사용할 채팅방을 열고 씬판독기를 엽니다.
2. 오른쪽 위 **톱니바퀴 → 모델 연결 → Jev 판독**에서 키를 입력합니다.
3. **키 저장 → 연결 확인**을 누릅니다.
4. **씬판독기 전체 사용**, **생성 직전에 자동 판독**을 켭니다.
5. 자동 전개 탭에서 **현재 세계관 → 프리셋 기본 세계관 사용**을 고릅니다.
6. 처음에는 판정 기준 **균형**, 최근 채팅 범위 **3턴**으로 시작해 결과를 확인합니다.
7. 평소처럼 메시지를 보냅니다. 짧은 알림으로 판독·주입 진행을 확인할 수 있습니다.

별도의 일반 모델 연결 프로필은 기본 씬 판독에 필수가 아닙니다. Jev 키만으로 시작할 수 있습니다.

화면에는 **자동 전개 / 고급 전개 / 갈등용 진행 / 인물 판정** 네 탭이 있습니다. 설정은 오른쪽 위 톱니바퀴, 닫기는 X입니다. 모바일에서는 창 안의 내용을 스크롤하며 사용하고 색상은 현재 SillyTavern 테마를 따릅니다.

### 한 응답이 만들어지는 과정

~~~mermaid
flowchart TD
    A["최근 RP와 현재 입력"] --> B["Jev가 장면과 가능한 진행을 판독"]
    B --> C["필요한 지시만 골라 조립"]
    C --> D["메인 RP 모델이 실제 응답 작성"]
    D --> E["다음 판독에서 실제 이행 확인"]
    E --> F["확인된 관계·사건 변화 저장"]
~~~

“고백하도록 지시했다”와 “실제로 고백했다”는 다릅니다. 계획을 세웠다고 관계나 사건을 완료 처리하지 않습니다. 다음 정상 판독에서 실제 출력을 확인한 뒤 반영합니다.

## 자동 전개

### 세계 반응 방향

유저를 둘러싼 세계가 어떤 방향으로 반응할지 정합니다.

- **자연스럽게**: 현재 설정과 사건 흐름을 따릅니다.
- **긍정적으로**: 가능한 반응 중 호의적인 쪽을 기본 방향으로 둡니다.
- **적대적으로**: 저항·불이익·마찰이 있는 쪽을 기본 방향으로 둡니다.

세계관이나 문체를 교체하는 설정은 아닙니다. 캐릭터 개인의 태도는 아래에서 따로 정합니다.

### 현재 세계관

이 채팅에 사용할 세계관을 **하나** 선택합니다. 고급 전개를 켜도 이 선택은 계속 사용할 수 있습니다.

- **프리셋 기본 세계관 사용**: 별도 세계관 전문을 추가하지 않습니다. 메인 모델은 기존 프리셋을 그대로 사용합니다. Jev는 최근 RP와 별도로 제공된 참고 자료 안에서만 세계를 파악합니다.
- **다른 세계관 선택**: 저장된 세계관 전문을 지정한 위치에 넣습니다. Jev는 해당 세계관의 짧은 판정 힌트를 참고합니다.

이 선택만으로 프리셋의 전체 내용이 Jev에 전달되는 것은 아닙니다. 로어북 참고도 별도 설정입니다.

세계관 추가·수정은 **고급 전개 → 세계관 관리**에서 합니다. 고급 전개 자체를 켜지 않아도 세계관을 선택하고 주입할 수 있습니다.

### 캐릭터→유저 관계 방향

- **상황에 따라 변화**: 현재 관계와 사건에 맞춰 반응합니다.
- **호의적**: 호의적인 관계 기본값을 사용합니다.
- **적대적**: 제공된 적대적 관계 지시문을 사용합니다.

이 방향은 고정 지시로 적용하고, Jev는 이번 장면에서 관계가 어떻게 움직일지를 따로 판단합니다. 호의적이라고 바로 사랑이 되거나 적대적이라고 세계 전체가 적대적으로 바뀌지는 않습니다.

### 판정 기준

- **보수적**: 진행 근거가 뚜렷할 때 움직입니다.
- **균형**: 현재 상황에 맞는 자연스러운 한 단계를 고릅니다.
- **적극적**: 가능한 행동·결정·거절·결과가 있다면 실제로 실행하는 쪽을 우선합니다.

적극적으로 바꿔도 인물의 지식, 이미 발생한 사건, 비밀을 아는 근거를 느슨하게 판정하지 않습니다. 새로운 사건이 부적합하면 현재 대화나 기존 사건을 움직일 수 있습니다.

### RP 진행 유형

기본 자동 전개에서 어떤 방식의 진행을 선호할지 정합니다.

- **사용 안 함**: 이 진행 유형의 보조 지시를 사용하지 않습니다. 확장 전체나 관계·갈등 기능을 끄는 버튼은 아닙니다.
- **자연 진행**: 기존 상호작용과 그 결과를 따라갑니다.
- **일상·생활 진행**: 생활 속 교류와 작은 변화로 움직입니다.
- **모험·임무 진행**: 목표, 탐색, 장애물과 시도를 중심으로 움직입니다.
- **조사·미스터리 진행**: 단서, 의심, 확인과 해석을 중심으로 움직입니다.
- **위협·생존 진행**: 위험, 자원, 대응과 생존 선택을 다룹니다.
- **세력·암투 진행**: 이해관계, 거래, 압박과 세력의 움직임을 다룹니다.
- **전쟁·작전 진행**: 작전 목표, 전황, 지휘·보급과 행동 결과를 다룹니다.

프리셋의 장르·문체를 덮는 설정이 아닙니다. **고급 전개를 켜면 이 선택은 잠기고**, 고급 전개의 사용 요소로 사건을 고릅니다. 현재 세계관은 잠기지 않습니다.

### 세 가지 속도는 서로 다릅니다

**전체 RP 호흡**은 글의 진행 밀도입니다. 느리게는 의미 있는 순간을 더 머물러 다루고, 빠르게는 사소한 반응·연결부·반복을 더 압축합니다.

**관계 진전 속도**는 관계 변화의 크기입니다. 호감만 뜻하지 않습니다. 거리 두기, 회피, 거절, 갈등, 자각과 고백 같은 변화도 포함합니다.

**사건 해결 속도**는 한 번에 얼마나 해결에 접근할지입니다. 느리게는 제한적인 진전과 남은 문제를, 빠르게는 근거가 있을 때 더 구체적인 결과를 허용합니다.

세 설정 모두 느리게 / 중간 / 빠르게 중 선택합니다. “몇 턴이면 고백”, “몇 턴이면 해결”처럼 정해진 횟수로 강제하지 않습니다. 빠르게 해도 유저의 대답이나 선택이 필요한 결과를 대신 확정하면 안 됩니다.

### 공통 인물 등장 확률과 새 사건 확률

**공통 인물 등장 확률**은 새 일반 NPC와 빌런의 추첨에 사용합니다. 5 / 10 / 20 / 35 / 50 / 100% 중 고릅니다. 이미 존재하는 인물을 매턴 새로 뽑는 확률은 아닙니다.

**새 사건 발생 확률**은 기본 자동 전개의 새 사건 추첨에 사용합니다. 고급 전개가 켜지면 잠기고 고급 전개의 **전개 개방도**를 사용합니다.

확률은 **등장·발생이 가능한 기회가 있을 때** 적용합니다. 100%라도 장면에 필요 없거나 설정상 불가능한 인물을 무조건 등장시키지 않습니다. 같은 기회에서 리롤할 때마다 당첨될 때까지 다시 뽑는 방식도 아닙니다.

## 판독 결과와 사건·인물 확인

**지금 판독**은 현재 입력과 최근 장면을 판독하는 버튼입니다. 자동 판독을 껐을 때도 사용할 수 있습니다. 메시지나 설정을 바꾼 뒤에는 새 판독이 필요합니다.

### 이번 턴 최종 적용

이번 응답에 실제로 넣기로 한 내용을 보여줍니다.

- **중심 전개**: 이번 응답에서 가장 중요한 진행 하나.
- **함께 넣는 변화**: 중심 전개와 직접 연결되는 작은 보조 진행. 없을 수도 있습니다.
- **이번에 넣지 않은 내용**: 다른 후보가 빠진 이유.
- **관계·사건·NPC·갈등용**: 각 영역에서 적용된 내용.
- **서술 호흡·실행 교정**: 반복이나 행동 회피를 줄이는 지시.
- **상태 반영**: 출력 대기인지, 실제 출력의 검증 대기인지.

체크한 기능을 매번 전부 넣지는 않습니다. 중심 진행 하나와 함께 가능한 보조 진행 최대 하나를 골라, 한 응답에서 사건·관계·인물이 한꺼번에 과속하지 않도록 합니다. 고정 설정과 필요한 지식 제한은 별도로 함께 적용할 수 있습니다.

### 추첨된 사건·인물

최종 적용 아래에서 **현재 중심 사건 / 일반 NPC / 빌런**을 확인합니다. 계기·목표·압박·동기·수단, 긍정/부정/양쪽 방향, 이번 응답의 사용 상태를 보여줍니다.

- **이번 턴 행동·진행**: 이번 응답에 사용합니다.
- **배경 유지·저장만 유지**: 기록은 남지만 이번 응답의 중심이 아닙니다.
- **검증 대기**: 선택한 계획이며 아직 실제 RP에서 이행됐다고 확정한 것은 아닙니다.
- **추첨 대기**: 이번 기회를 통과하지 못해 다음 적합한 기회를 기다립니다.
- **확장 추첨 외 사건 / 현재 장면 NPC**: 확장이 만든 것이 아니라 채팅에서 확인한 사건·인물입니다.

**사건 끝내기**는 확장에 저장된 중심 사건을 종료합니다. 다음 적합한 기회부터 새 사건을 판단합니다. 실제 채팅을 고치거나 “사건이 해결됐다”는 서술을 대신 작성하지 않습니다.

### 상세 결과와 실행 교정

장면·관계, 사건·NPC, 고급 전개, 연속성, 갈등·실행 품질, 저장 상태와 실제 주입문을 영역별로 접어 볼 수 있습니다.

상세 판정에서는 최초 선택과 확신도, 최종 적용값, 조정·제외 이유를 확인합니다. “판정은 됐는데 왜 안 나왔지?” 싶을 때 최종 적용과 함께 보세요. **실제 주입문**은 모델에게 보내는 영어 지시이므로 화면 설명과 문장이 다를 수 있습니다.

오른쪽 위 **클립보드 아이콘**은 현재 탭과 관련된 Jev의 원선택, 확신도, 최종 조정, 추첨·이행 결과를 간단한 JSON으로 복사합니다. 이 버튼에는 채팅 원문과 실제 주입문이 포함되지 않습니다.

설정의 **검사용 전체 판정 기록**은 별도입니다. **전체 판정 열기**를 누르면 메모리에 남은 최근 Jev 요청의 RP·OOC 원문, 질문, 응답, 조정 결과와 최종 주입문을 편집 가능한 미리보기로 보여줍니다. API 키·흔한 연락처 형식은 자동으로 가리며 제작자 전용 원문도 제외합니다. 개인정보가 남지 않았는지 직접 확인·수정한 뒤 **검토한 내용 복사**를 누르세요. 원문 요청은 재시작하거나 다른 채팅으로 이동하면 남지 않을 수 있습니다.

망설임, 같은 거절의 반복, 빙빙 도는 대화, 불필요한 질문으로 턴 넘기기, 입력 되풀이, 말만 하고 행동하지 않기 등은 별도 체크 없이 확인합니다. 필요할 때 짧은 교정 지시를 우선순위에 따라 넣습니다.

모든 질문이나 거절을 금지하지는 않습니다. 실제 유저의 선택이 필요한 질문, 캐릭터에게 타당한 거절은 유지해야 합니다. 최종 표현은 메인 RP 모델이 작성하므로 개선 정도는 모델과 프리셋에 따라 달라집니다.

## 고급 전개

### 고급 전개 사용

켜면 기본 RP 진행 유형과 기본 새 사건 확률 대신 **선택한 세계관 + 사용할 요소 + 전개 개방도**로 진행합니다. 관계 방향·속도, 전체 RP 호흡, 갈등용 진행, 인물 판정은 함께 작동합니다.

안전한 장소에서도 납득할 만한 원인이 있으면 뜻밖의 방문이나 위협이 생길 수 있습니다. 다만 공포 요소를 켰다는 이유만으로 현실 세계에 갑자기 유령을 만들지는 않습니다.

### 전개 개방도

새 사건이 가능한 기회에서 적용하는 추첨 확률입니다.

- **보수적**: 18%
- **균형**: 35%
- **적극적**: 58%
- **매우 적극적**: 75%

자동 전개 탭의 **판정 기준**과 다릅니다. 판정 기준은 가능한 진행을 얼마나 적극적으로 고를지, 개방도는 고급 새 사건의 기회를 얼마나 자주 통과시킬지 정합니다.

### 사용할 요소

여러 개를 켤 수 있지만 한 번에 전부 주입하지 않습니다.

- **일상·교류**: 생활, 만남, 사회적 교류와 작은 변화.
- **탐험·발견**: 장소, 통로, 자원과 새로운 발견.
- **사건·목표**: 과제, 사고, 목표와 장애물.
- **추리·수사**: 단서, 증언, 의심과 조사.
- **위협·전투**: 공격, 추적, 충돌과 위험 대응.
- **공포·초자연**: 불안과 위협. 초자연 현상은 세계관에 근거가 있을 때만.
- **암투·공작**: 거래, 음모, 정보전과 이해관계.
- **관계·치정**: 경쟁, 관계 압박과 사적인 갈등.

NPC나 존재가 필요하면 저장된 후보를 재사용하거나 새로 추첨합니다. 주요 개별 인물과 군중·지나가는 인물은 필요한 비중에 맞춰 다룹니다. 원작 세계에서는 장소·시대·역할에 맞는 원작 인물도 고려하되 유명하다는 이유로 억지 등장시키지 않습니다.

### 세계관 관리

접이식을 열면 커스텀 세계관 목록이 보입니다. **+**로 새 항목을 만들고, 저장된 항목을 눌러 수정합니다.

- **이름**: 자동 전개 탭의 세계관 선택 목록에 보일 이름.
- **원작·프랜차이즈 세계**: 해리포터처럼 정해진 원작 인물을 고려해야 할 때 켭니다.
- **Jev 판정 힌트**: 가능한 사건과 금지된 전개를 판단하는 짧은 세계 규칙. 예: “현대 현실 대학. 초능력 없음. 학기와 동아리 활동 중심.”
- **주입 전문**: 메인 RP 모델에 전달할 실제 세계관 프롬프트.

힌트를 비우면 이름과 전문에서 짧은 문구를 자동으로 뽑습니다. **AI가 전문을 이해해 새로 요약하는 기능은 아니므로**, 중요한 제한이 빠졌다면 직접 고치세요. 전문 전체는 Jev가 매번 읽지 않습니다.

**저장하고 목록으로**는 저장 후 편집기를 닫습니다. **목록으로 돌아가기**는 편집을 그만둡니다. **삭제**는 해당 커스텀 세계관을 지웁니다.

**전체 JSON 복사**는 커스텀 목록을 복사합니다. **JSON 가져오기**에 그 내용을 붙여넣고 적용하면 **기존 커스텀 목록을 가져온 목록으로 교체**합니다. 추가 병합이 아니므로 필요한 목록은 먼저 복사해 두세요.

기본 제공 선택지는 프리셋 기본 세계관, 범용 판타지, 현대 판타지·초자연, SF·미래, 슈퍼히어로, 좀비·감염, 포스트아포칼립스, 심령·퇴마, 크리처·괴물, 시대·역사 배경, 현대 대학·캠퍼스입니다. 대학·캠퍼스는 해당 국가와 시기에 맞는 학사·생활·스포츠 맥락을 사용하도록 돕는 지시이며 실시간 학사일정을 조회하지는 않습니다.

초기 커스텀 목록에는 일반세계, 해리포터, 메이저장르 통으로, 웨어울프, 오메가버스가 들어 있습니다. 각 세계관은 독립적으로 하나씩 선택합니다. 기본 제공 목록을 변형하고 싶으면 새 커스텀 항목으로 작성하세요.

## 갈등용 진행

기존 갈등 프롬프트를 따로 관리하는 탭입니다. 선택한 전개 장르가 바뀌어도 갈등 설정은 유지됩니다.

### 부정 편향을 최우선으로 사용

켜면 **이 탭에서 활성화한 갈등 지시를 기반으로** 다른 관계·사건 전개를 조정합니다. 다른 진행 때문에 부정 편향이 무효화되는 것을 막기 위한 설정입니다.

이것만 켠다고 아래 갈등 항목이 모두 켜지는 것은 아닙니다. 사용할 항목도 선택해야 합니다.

### 싸움조장

- **싸움 유지**: 실제 갈등 장면에서 싸움을 지나치게 빨리 수습하지 않도록 합니다. 장면별로 Jev가 적용 여부를 정합니다.
- **빌런 자동**: 장면에 맞는 빌런의 생성·재사용·개입을 허용합니다. 새 추첨은 공통 등장 확률을 따릅니다.
- **갈등 속 NPC 활성화**: NPC가 실제 참여하거나 이번 응답에 들어올 때 자기 이해관계와 행동을 가진 인물로 움직이게 합니다. 아무 NPC도 없는데 상시 등장시키는 기능은 아닙니다.
- **현재 빌런 종료 · 새 추첨 대기**: 확장에 저장된 빌런을 종료하고 다음 적합한 기회를 기다립니다. 채팅 속 인물을 삭제하지 않습니다.

### 세계·관계 편향

**세계 적대성 / NPC 특별취급 방지 / 유저 불운**은 켜 둔 항목을 고정 지시로 사용합니다. 장면마다 Jev가 마음대로 끄는 선택이 아닙니다. NPC 특별취급 방지는 NPC들이 유저라는 이유만으로 일방적으로 편들거나 우대하는 방향을 억제합니다.

일반 RP 응답에 적용하며 OOC-only에는 기본적으로 확장 주입을 비웁니다. 아래 검사용 OOC 1회 유지 기능은 예외입니다.

### 제작자 전용 주입

설정의 제작자 모드를 해제하면 접이식 입력란이 나타납니다. **전용 원문 → 전용 저장소에 저장**으로 보관한 뒤 **이 채팅에서 전용 원문 사용**을 켭니다.

배포본에는 개인 전용 원문이 들어 있지 않습니다. 잠금 해제는 입력 영역을 여는 기능이며 데이터를 암호화하는 보안 금고는 아닙니다. 개인 원문은 사용자 저장소에만 보관됩니다.

## 인물 판정

짧은 시트가 한두 성격으로 납작해지거나, 인물이 본 적 없는 비밀을 아는 듯 말하는 일을 줄이기 위한 선택 기능입니다. 기본 사건·NPC 생성은 그대로 두고, **등록한 캐릭터와 NPC의 행동 해석**을 따로 맡습니다. NPC 시트는 직접 입력합니다.

### 사용과 시트 저장

**인물 판정 사용**을 켜면 현재 채팅에서 등록한 시트를 매턴 판독의 참고자료로 사용합니다. 끄면 시트와 저장 규칙은 보관하되 인물 고급 주입은 하지 않습니다.

**캐릭터 / 페르소나 / NPC 시트**에서 +를 눌러 한 사람씩 등록합니다. 이름과 원문 시트를 붙여넣고 **시트 저장**을 누르세요. 이 단계는 모델을 호출하지 않습니다. NPC의 별칭을 비워두면 이름의 확인 가능한 짧은 호칭과 시트에 명시된 별칭만 자동으로 채웁니다. 직접 입력한 별칭은 그대로 유지합니다. 페르소나는 참고자료이며 확장이 페르소나의 대사나 행동을 대신 결정하지 않습니다.

**이 채팅에서 유저 사칭 허용**을 켜면 현재 장면의 페르소나도 이번 턴 인물 판정 후보가 됩니다. 끄면 다른 인물의 지식 경계를 판단하는 참고자료로만 쓰며, 유저의 미정 행동을 확정하지 않습니다.

NPC는 이름만 먼저 등록할 수 있습니다. **시트의 NPC 읽어오기**는 현재 캐릭터 카드·페르소나·연결 로어북에서 이름 후보만 찾아 보여주고, 체크한 사람만 등록합니다. 이름을 선택했다는 이유로 시트를 자동 생성하지 않습니다. NPC 시트 입력칸의 회색 안내는 적으면 사라지는 예시이며 저장 내용이 아닙니다. 역할·관계·동기·말투·지식·능력·접근 범위 중 확인된 내용을 직접 적어 주세요. 빈칸을 억지로 채우거나 비밀·전문성·접근권을 만들어 넣을 필요는 없습니다.

NPC 편집의 **역할**에서 **악역 / 선역 / 양면** 중 하나를 고릅니다. 선악이 분명하지 않거나 상황에 따라 양쪽으로 움직이는 인물은 **양면**으로 두세요. 새 NPC의 기본값도 양면입니다. 이는 Jev의 장면 판정 참고값일 뿐, 악역도 선역도 한 가지 성격·행동으로 고정하지 않습니다. 구체적인 동기와 대립·협력 방식은 시트와 실제 RP를 따릅니다. 이전 버전의 악역 체크는 악역으로 옮겨지고, 체크하지 않은 NPC는 양면이 됩니다.

**메인 RP 모델도 이 원본 시트를 이미 읽음**은 캐릭터 카드·페르소나·활성 로어북 등으로 같은 내용이 메인 모델에 전달된다면 켭니다. 씬판독기에만 따로 저장한 NPC는 끕니다. 끈 NPC가 실제 참여할 때에는 이름과 역할 등 최소 정체성을 함께 주입합니다. 켠 인물에게는 원본을 반복해서 넣지 않습니다.

시트 저장 후 **인물 판정 실행**을 누르면 선택한 SillyTavern 연결 프로필의 모델이 오래 쓸 만한 짧은 영어 규칙을 만듭니다. 행동·관계·지식/능력/접근·대화 방식 중 시트가 뒷받침하는 내용만 저장하며, 빈약한 시트를 채우려고 억지로 항목을 늘리지 않습니다. 이 단계에서는 Jev를 호출하지 않습니다. 형식이 잘못됐거나 영어 주입 규칙이 아닌 항목은 제외됩니다. 쓸 만한 규칙이 0개인 것도 정상 결과입니다.

시트를 고치면 **시트 저장 → 인물 판정 실행** 순서로 다시 진행하세요. 새 원문이 저장되면 예전 분석은 현재 판정에 적용되지 않습니다. 분석 실패 시 이전 결과는 보관되지만, 수정된 시트에 대한 결과로 재사용하지 않습니다. 분석 중 시트를 다시 수정하거나 채팅을 이동하면 늦게 도착한 결과는 저장하지 않습니다. **삭제**는 해당 등록 시트를 지웁니다.

### 화면에서 결과 보기

**저장된 인물 판독 기준**에서 왼쪽의 이름을 누르면 오른쪽에 종류별 한국어 이름과 저장된 영어 규칙을 볼 수 있습니다. 형식 검사에서 제외된 항목이 있으면 이유도 펼쳐 볼 수 있습니다. 저장 규칙은 고정 능력치가 아니며 매턴 모두 주입되지 않습니다.

**이번 턴 인물 판정**에서는 누가 현재 장면에서 실제 역할이 있는지, 어떤 저장 기준이 최종 주입됐는지, 지식 접근이 없어 무엇이 빠졌는지, 어떤 반응 방향이 제안됐는지 확인할 수 있습니다. 확신도를 켜면 Jev 선택과 최종값을 함께 볼 수 있습니다. 아무 항목도 고르지 않는 결과도 정상입니다. 길이 제한 때문에 빠진 규칙은 문장 중간을 자르지 않고 항목 전체를 제외해 표시합니다.

### 매턴 적용 방식

최근 RP는 발화자와 시점을 지닌 원문 근거로 Jev에 보여줍니다. 대사의 주장·추측·계획을 확정된 세계 사실로 바꾸지 않습니다. 참메모리와 연결 로어북은 별도 참고자료이며, 거기 적힌 내용도 모든 인물이 자동으로 아는 정보가 아닙니다.

Jev가 한 번의 요청에서 이번 RP에 필요한 저장 규칙 0~2개와 정보 접근 경로, 다음 반응 방향을 고릅니다. 확장은 그 결과의 모순을 다시 확인합니다. 정보 접근이 없으면 그 정보와 거기에 의존한 행동 방향을 제외합니다. 인물당 시트 규칙 최대 2개, 상황 정보 최대 2개는 **상한**이며 목표 개수가 아닙니다. 실제 주입은 필요한 문장만 짧게 조립하고 길이가 넘으면 우선순위가 낮은 문장 전체를 뺍니다.

시트 등록 인물은 인물 판정을 끄거나 규칙을 0개 골라도 기존 일반 NPC 추첨의 소유로 바뀌지 않습니다. 공통 전개는 등장 가능성을 다루고, 등록된 인물의 성격·지식·반응은 인물 판정이 담당합니다. 씬판독기에만 저장해 메인 모델이 원본을 못 보는 활성 NPC에게는 짧은 영어 식별 정보를 따로 전달합니다. 제안된 반응은 계획일 뿐 실제 발생한 사실이 아니며, 출력 확인 전에 관계·사건 상태로 누적하지 않습니다.

## 설정

### 기본 설정

**씬판독기 전체 사용**을 끄면 판독과 기본 주입, 두 매크로 출력을 중단합니다. 저장 자료를 삭제하지는 않습니다.

**생성 직전에 자동 판독**을 끄면 전송할 때마다 새 판독하지 않습니다. 필요할 때 자동 전개의 **지금 판독**을 누르세요. 현재 입력·설정과 맞는 저장 판정이 없으면 예전 판정을 억지로 적용하지 않습니다.

**화면에 확신도 표시**는 결과의 신뢰 정도를 보여 주는 화면 설정입니다. 끈다고 판정 기준이 달라지지 않습니다.

**최근 채팅 범위**는 1~5턴 중 선택합니다. 한 턴은 유저 입력부터 이어지는 캐릭터 출력까지입니다. 생성 직전의 **현재 유저 입력도 최신 미완성 턴으로 셉니다.** 따라서 1턴은 현재 입력만 포함하고 직전 캐릭터 응답이 빠질 수 있습니다. 직전 대화까지 보려면 2턴 이상을 사용하세요. 기본값은 3턴이며 아주 긴 기록은 최신 부분을 우선해 길이를 제한합니다.

### Jev 연결

- **Jev API 키**에 입력한 뒤 **키 저장**을 누릅니다.
- **눈 아이콘**은 입력 칸의 표시·숨김을 바꿉니다.
- **연결 확인**은 실제 Jev 요청으로 연결 여부를 확인합니다.
- 저장 상태에는 키 전체 대신 일부 끝자리만 표시합니다. 빈 입력 칸이라고 저장이 풀린 것은 아닙니다.

Jev 주소와 모델은 서버 플러그인에 고정되어 있어 따로 입력하지 않습니다. 기본 판독은 계속 Jev를 사용합니다.

### SillyTavern 연결 프로필과 연속성 추론

SillyTavern 본체의 API 연결 메뉴에 **저장해 둔 연결 프로필**을 선택합니다. 별도 모델 주소나 키를 씬판독기에 다시 넣지 않습니다.

- **프로필 새로고침**: 본체에서 추가·수정한 프로필을 목록에 다시 가져옵니다.
- **연결 확인**: 선택한 프로필로 짧은 실제 요청을 보냅니다. 성공 시 사용 모델을 알림에서 확인합니다.
- **연속성 추론 사용**: 약속·일정·위임·중요 정보 전달처럼 이어져야 할 내용을 보조 모델이 후보로 찾게 합니다.

후보는 다음 정상 Jev 판독에서 확인한 뒤 반영합니다. “약속했다”를 “실행했다”로 저장하지 않고 실제 관계·사건 상태와도 구분합니다. 작업이 늦으면 다음 판독을 무기한 기다리게 하지 않습니다.

연결 프로필은 인물 시트의 후보 추출에도 사용합니다. **프로필 선택과 연속성 추론 켜기는 별개**입니다. 이 모델이 기본 Jev 판독을 대신하지는 않습니다.

### 기억 참고 · 현재 채팅

**참메모리 연동**과 **캐릭터에 연결된 로어북 참고**를 독립적으로 켭니다. 하나만 사용하거나 둘 다 사용할 수 있습니다. 둘 다 꺼도 기본 최근 채팅 판독은 계속됩니다.

**참메모리 연동**은 참메 제작자가 제공하는 읽기 기능에서 현재 이야기의 요약·남은 약속 등 참고 내용을 받습니다. 임베딩 저장소 전체를 복사하지 않으며 참메의 기억을 수정·삭제하지 않습니다. 해당 읽기 기능을 제공하는 참메 버전이 필요합니다.

**캐릭터에 연결된 로어북 참고**는 현재 캐릭터의 기본 책과 보조 책에서 최근 RP와 키가 맞는 항목 및 항상 포함 항목을 고릅니다. 비활성 항목, 인물 포함·제외 조건, 보조 키 조건, 대소문자·단어 일치와 정규식 키를 고려합니다.

관련 키가 맞는 내용을 우선하며 최대 8항목·합계 약 6,000자, 항목당 약 1,600자로 제한합니다. 전역 로어북 전체, 다른 캐릭터의 모든 책, 과거 채팅 전체를 자동으로 읽지 않습니다. SillyTavern의 재귀 검색·쿨다운·추첨 등 **전체 로어북 발동 과정을 재현하는 기능도 아닙니다.**

그 아래 상태에서 사용 안 함, 참고함, 길이 제한, 맞는 항목 없음, 읽기 실패 등을 확인합니다. 여러 책 중 일부만 실패하면 읽은 자료는 사용합니다. 사용할 수 없는 자료가 있다고 기본 판독 전체를 막지는 않습니다.

두 자료는 **Jev의 참고용**입니다. 원문을 메인 RP 프롬프트에 다시 붙이지 않으며 읽은 비밀을 모든 인물이 알고 있다고 취급하지 않습니다. 기본 주입과 매크로 주입 어느 쪽에서도 같은 방식으로 읽습니다.

### 주입 위치

“주입”은 모델이 응답을 만들기 전에 짧은 지시를 함께 보내는 것입니다. 채팅 메시지로 따로 나타나는 것은 아닙니다.

**1. 기본 판정·전개 주입**은 이번 턴의 관계·사건·인물·갈등 지시입니다.

**2. 세계관 전문 주입**은 선택한 세계관의 저장 프롬프트입니다. 고급 전개 사용 여부와 별개입니다.

두 항목의 위치를 각각 선택합니다.

- **기본 · 깊이 0 · system**: 확장이 정해진 위치에 자동으로 넣습니다. 처음에는 이 방식을 사용해도 됩니다.
- **프리셋 · 매크로 위치**: 아래 표시된 매크로를 프리셋의 원하는 프롬프트에 한 번 넣습니다.

기본 판정·전개용:

~~~text
{{scene-reader}}
~~~

세계관 전문용:

~~~text
{{scene-reader-world}}
~~~

옆의 **복사** 버튼으로 복사하세요. 매크로 방식을 선택하고 실제 프리셋에 매크로를 넣지 않으면 해당 내용이 전달되지 않습니다. 선택한 항목은 기본 위치와 매크로 위치에 중복 주입하지 않습니다.

프리셋 기본 세계관 사용을 선택하면 세계관 전문 자체가 비어 있는 것이 정상입니다. 사용자 매크로를 지원하지 않는 환경에서는 안내 후 기본 위치를 사용합니다.

### 제작자 모드

비밀번호를 입력하고 **잠금 해제**를 누르면 갈등용 진행 탭에 전용 원문 입력 영역이 열립니다. 해제 상태는 해당 SillyTavern 사용자 설정에 저장됩니다. 다른 설치나 사용자 계정으로 옮기면 같은 상태가 자동으로 따라오지는 않습니다.

### 현재 채팅 초기화

확장이 관리하는 상태를 정리합니다. 실제 채팅과 원본 캐릭터 카드를 삭제하지 않습니다.

- **관계 누적만 초기화**: 쌓인 관계 판정과 관계 진행 기록을 비웁니다.
- **현재 사건 종료**: 중심 사건을 종료하고 다음 사건 기회를 기다립니다.
- **현재 일반 NPC 종료**: 확장이 추첨한 일반 NPC를 종료합니다. 등록해 둔 NPC 시트를 삭제하는 기능은 아닙니다.
- **판정·관계·사건·인물 전체 초기화**: 판정 결과, 추첨된 인물·사건, 관계·연속성·배경 활동과 복원 기록을 비웁니다. 저장한 시트와 사용자 선택 설정은 유지합니다.

초기화 후에는 해당 상태의 이전 리롤 복원 기록도 정리될 수 있습니다. 필요한 기록은 백업으로 남겨 두세요.

### 데이터 백업

**지금 백업**은 설정, 채팅 상태, 세계관, 인물 시트를 서버의 별도 백업으로 보관합니다. 목록에 날짜와 시간이 표시됩니다.

- **복원**: 그 백업 시점으로 확장 데이터를 되돌립니다. 현재 채팅 하나만의 복원이 아니라 백업에 담긴 전체 자료 대상입니다. 복원 전 현재 자료도 자동 백업합니다.
- **다운로드**: 다른 장치에 보관할 JSON 파일을 내려받습니다.
- **삭제**: 해당 백업 파일만 지웁니다. 현재 사용 중인 데이터를 초기화하지 않습니다.
- **백업 가져오기**: 내려받은 JSON 파일을 선택해 복원합니다.

서버 내부 백업에는 키와 개인 전용 원문도 보관될 수 있습니다. **다운로드 파일은 API 키와 제작자 전용 원문, 이를 포함할 수 있는 주입 기록을 제외**합니다. 그러나 인물 시트와 이야기 정보는 포함되므로 개인 자료로 보관하세요. 다른 설치에 가져왔다면 키와 전용 원문은 다시 설정해야 합니다. SillyTavern 자체의 연결 프로필도 별도로 관리합니다.

## OOC와 검사용 주입

OOC는 캐릭터의 대사가 아닌 감독 지시입니다. **(OOC: ...)** 또는 **[OOC: ...]**를 대소문자 구분 없이 인식합니다. OOC_CHAT에서 보낸 표식 있는 메시지도 인식하며 그 메시지의 실제 본문을 읽습니다.

### OOC만 입력한 경우

예: “(OOC: 문장을 더 자연스럽게 써.)”

씬판독기는 **Jev 판독을 하지 않고 기존 주입도 비웁니다.** 일시정지 알림을 표시하며 원래 메시지는 수정하지 않고 메인 모델로 보냅니다. 현재 버전에서는 항상 적용합니다.

### RP와 OOC를 함께 입력한 경우

예: RP 대사 뒤에 “(OOC: 아직 화해하지 말고 이번에는 거리를 두게 해.)”

RP는 실제 장면 근거로, OOC는 이번 진행의 방향·제약으로 구분합니다. “싸우게 해”라는 지시만으로 이미 싸웠다고 기록하지 않습니다. 문체·언어·출력 길이 지시는 메인 모델이 처리하도록 두고 Jev의 사건 판정에 섞지 않습니다.

읽는 최근 범위 안의 과거 OOC도 RP에서 분리합니다. 과거의 “이번엔 먼저 나가게”를 계속 재실행하지 않습니다. 아직 유효한 지식 제한·세계 사실·관계 상태 등만 연속성 참고로 사용합니다. 장기간 유지할 설정은 프리셋·시트·로어북에 보관하세요.

원래 입력은 그대로 남습니다. OOC 원문을 별도 지시문으로 중복해서 다시 넣지 않습니다. 알림에는 OOC 지시를 함께 확인하고 있다는 상태가 표시됩니다.

### 다음 OOC에 직전 주입문 유지

출력이 이상해서 어떤 지시가 들어갔는지 물어보고 싶을 때 사용하는 **검사용 1회 기능**입니다.

1. 판독이 끝난 상태에서 설정의 **다음 OOC에 직전 주입문 유지**를 누릅니다.
2. 다음 입력을 OOC-only로 보냅니다.
3. Jev를 새로 호출하지 않고 직전 주입을 유지한 상태로 메인 모델이 답합니다.
4. 검사용 응답이 끝나면 주입을 비우고 정상 동작으로 돌아갑니다.

검사용 답변은 관계·사건·NPC 이행과 배경 활동의 근거에 넣지 않습니다. 다음 입력이 RP라면 검사용으로 처리하지 않습니다. 모델에게 질문한 답이 실제 프롬프트의 정확한 복사본이라는 보장은 없으므로 보낸 지시 자체는 화면의 **실제 주입문**도 함께 확인하세요.

## 리롤·수정·삭제와 저장

같은 입력의 리롤은 가능하면 같은 판정과 추첨을 재사용합니다. 같은 RP여도 OOC 지시를 바꾸거나 판정에 영향을 주는 설정·자료를 바꾸면 이전 판정을 그대로 재사용하지 않습니다.

출력을 수정·삭제하거나 다른 답변으로 넘기면 그 출력에 연결된 확장 상태도 되돌리거나 다시 검증하도록 바꿉니다. 처리 알림이 표시됩니다. **최근 12개의 복원 기록**보다 더 오래된 내용을 바꾸면 정확한 과거 상태 대신 누적 판정을 비우고 다음 RP에서 다시 판독합니다. 시트와 선택 설정은 유지합니다.

현재 채팅의 방향·속도·갈등·세계관 선택·기억 연동·인물 시트와 판정 상태는 채팅별로 관리합니다. Jev 키, 연결 프로필 선택, 전체 사용·자동 판독·최근 범위 같은 기본 설정, 세계관 목록과 전용 원문은 사용자 공통으로 관리합니다.

저장 위치는 SillyTavern **사용자 데이터 아래의 scene-reader 폴더**입니다. 일반적인 기본 사용자 설치에서는 다음 위치입니다.

~~~text
SillyTavern/data/default-user/scene-reader/
~~~

사용자 계정이나 데이터 경로를 바꿨다면 위치도 달라집니다. 저장할 때 필요한 폴더를 플러그인이 자동으로 만듭니다. 캐릭터 원본 폴더나 참메 저장소를 수정하지 않습니다.

화면 확장이나 플러그인 폴더를 교체해도 이 데이터 폴더를 지우지 않으면 자료는 남습니다. 서버 자체를 잃는 경우에 대비하려면 백업을 다운로드해 별도로 보관하세요.

## 자주 묻는 질문

### 선택한 기능이 왜 이번 턴에는 안 나왔나요?

선택은 사용을 허용하는 것이고 모든 항목의 매턴 실행을 보장하지 않습니다. 장면에 맞는 근거가 없거나 추첨에 실패했거나 이번 중심 진행과 충돌해 제외될 수 있습니다. **이번 턴 최종 적용 → 이번에 넣지 않은 내용**, 사건·인물 카드, 상세 판정을 확인하세요.

적극적이어도 의미 없는 새 사건을 강제로 만들지는 않습니다. 새 사건이 어렵다면 기존 사건, 관계 압력, 현재 대화와 행동의 결과로 진행할 수 있습니다.

### 인물의 저장 기준과 실제 주입이 왜 다르죠?

저장 기준은 판단용 자료이고 이번 턴에는 관련된 일부 경계만 골라 보냅니다. 등록한 인물이 장면과 무관하면 아예 주입하지 않을 수 있습니다. 시트 전체와 모든 분석을 매번 보내는 구조가 아닙니다.

### 연결 프로필 목록이 비어 있어요

SillyTavern 본체의 API 연결 메뉴에서 먼저 프로필을 저장하세요. API에 연결돼 있는 것과 프로필로 저장해 둔 것은 다를 수 있습니다. 이후 씬판독기의 **프로필 새로고침**을 누릅니다. 기본 Jev 판독에는 이 프로필이 없어도 됩니다.

### 404 / 인증 실패 / 시간 초과가 떠요

- **404**: 플러그인 폴더 위치, 파일 세 개, enableServerPlugins, 서버 재시작을 확인하세요.
- **401·403**: Jev 키 저장 상태와 키의 유효성을 확인하세요.
- **502·시간 초과**: SillyTavern 서버에서 Jev 서비스로 연결되는지 확인하세요.
- **저장 오류**: 사용자 데이터 폴더의 접근 권한과 여유 공간을 확인하세요. 오류를 고치기 전에 데이터 폴더를 지우지 마세요.

### 토스트 알림은 언제 나오나요?

판독 중에는 하나의 진행 알림을 갱신하고 성공 또는 오류로 마무리합니다. 혼합 입력의 OOC 확인, OOC-only 일시정지, 기존 판정 재사용, 출력 변경에 따른 복원도 알립니다.

저장·삭제·복사·백업 같은 명시적 작업은 결과를 알리고 일반 선택·토글 변경마다 성공 알림을 쌓지는 않습니다. 오래 걸리는 인물 분석도 완료되면 진행 알림이 끝나야 합니다.

### 얼마나 느려지고 토큰은 얼마나 쓰나요?

새 판독에는 Jev 요청이 추가됩니다. 최근 범위와 활성 기능, 인물·기억 참고가 많을수록 입력과 질문도 늘어납니다. 같은 판정을 재사용하면 새 Jev 호출을 줄일 수 있습니다.

연결 프로필을 사용하는 시트 후보 추출과 연속성 추론은 해당 모델 사용량도 발생합니다. 연결 확인도 실제 요청입니다. 요금은 서비스와 모델에 따라 다르므로 고정 금액으로 안내하지 않습니다.

디스크에 시트를 저장해 둔 것만으로 매턴 그 전문이 메인 모델 토큰에 더해지지는 않습니다. 다만 이번 판독에 제공한 자료는 Jev·보조 모델 입력량에, 최종 주입문은 메인 모델 입력량에 포함됩니다. 선택한 세계관 전문도 실제로 주입하는 만큼 길이를 사용합니다.

### 어떤 프리셋을 꺼도 되나요?

세계관 전문을 확장으로 똑같이 옮겨 같은 역할로 주입하고 있다면 프리셋의 중복 원문은 정리할 수 있습니다. 위치와 실제 주입을 먼저 확인하세요.

그 외 캐릭터성·문체·시점·지식 분리 전체를 이 확장이 완전히 대체하지는 않습니다. 최근 범위 밖의 모든 과거와 모든 로어북을 읽지 않기 때문에 프리셋의 광범위한 지식·연속성 규칙을 일괄 삭제해도 된다고 보장하지 않습니다.

### 배포 파일에 내 키나 시트가 들어가나요?

배포 ZIP은 확장 실행 파일과 안내 문서만 묶습니다. 사용자 저장소의 키·시트·채팅은 포함하지 않습니다. 직접 만든 백업에는 개인 이야기와 시트가 담길 수 있으므로 배포 ZIP과 구분하세요.

판독할 때 선택한 최근 채팅과 관련 참고 자료는 연결한 모델 서비스에 전송됩니다. “로컬에 저장한다”는 말이 “판독도 오프라인으로 한다”는 뜻은 아닙니다.
